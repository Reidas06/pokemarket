# PokéMarket

Aplicación móvil desarrollada con React Native, TypeScript y Expo para explorar un catálogo de cartas Pokémon.

## Requisitos

- Node.js y npm.
- Expo Go instalado en un dispositivo Android compatible.
- Ordenador y móvil conectados a la misma red Wi-Fi para probar la aplicación.

## Instalación

1. Clona el repositorio.
2. Accede a la carpeta del proyecto.
3. Instala las dependencias:

   ```bash
   npm install
   ```

## Ejecución

Inicia el servidor de desarrollo:

```bash
npm start
```

Escanea el código QR con Expo Go para abrir la aplicación en el móvil.

## Tecnologías

- React Native
- TypeScript
- Expo

## Estado del proyecto

La aplicación cuenta con una pantalla inicial y una identidad visual basada en los colores rojo, blanco y negro. El catálogo y las funcionalidades de búsqueda, detalle de producto y carrito se desarrollarán progresivamente.
